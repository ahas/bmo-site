## 控制台分为三栏

用安装时设定的名称和密码登录控制台后，页面分为三栏。

- **左侧边栏：** 通往各个页面、房间和智能体的入口。
- **中间：** 当前打开的页面或房间。
- **右侧 TODO 面板：** 交给 BMO 的工作以条目形式堆积在这里。平台管理员的控制台才有。

平台管理员的首页一眼展示房间和智能体此刻在做什么，成员的首页则是自己的房间列表。在手机上，侧边栏以抽屉形式打开，TODO 面板用顶部栏的“打开 TODO”打开。

## 侧边栏

- **“搜索…”** 最上方的搜索在任何地方都能用 Ctrl+K（Mac 上是 ⌘K）打开。可以查找页面及其标签页、房间、智能体，也能按名字查找同一组织的人。
- **页面分组：** 分为三组。
  - “系统服务”：照看部署的管理页面，以及负责人们使用的页面。“组织”“平台设置”“代理中心”“Brain”等都在这里。
  - “应用”：“笔记”“日历”“制品”“应用目录”这类日常使用的页面。
  - “我的应用”：我的 BMO 为我做的个人应用的页面。
- **“房间”：** 我的房间列表。置顶的房间排在最上面；有新消息时房间会移到上方，并显示未读数。
- **“智能体”：** 平台管理员能看到的主管、角色和仓库列表。
- **下方的用户菜单：** 点自己的名字，有“设置”、桌面应用下载、显示模式（浅色·深色·跟随系统）和“退出登录”。

侧边栏只显示我能打开的页面。一个页面都没有的分组，连标题也不显示。

## 房间

房间是 BMO 和人对话的地方。

- **与 BMO 的个人房间：** 只有我和我的 BMO 两个人的聊天房间。在下方输入框（“对 BMO 说”）中输入，BMO 就会回答。也可以用回形针按钮附上文件。
- **群组房间：** 在侧边栏房间标题旁的“新聊天”中点“创建控制台房间”，填写“房间名称”即可创建。这是不需要聊天服务、只在控制台中使用的房间，由创建者的 BMO 回答。
- **添加成员：** 房间的创建者或他的负责人，可以在“房间信息”的“成员”标签页中用“添加成员”一次加入多人或整个组织。打开“允许呼叫”后，加入的人可以在房间里按名字呼叫自己的 BMO。
- **“呼叫权限”：** “房间信息”中的一个标签页，显示并修改谁可以在这个房间里呼叫自己的 BMO。
- **“与我的 BMO 单独对话”：** 在群组房间的菜单中。群组房间保持不变，旁边打开一个面板，与我的 BMO 单独交谈。在这里说的话不会发到群组房间。
- **“在对话中查找”和置顶：** 在房间的菜单中查找对话，或置顶、取消置顶房间。

把 Telegram 或 Discord 的房间添加到控制台后，它们也会一起出现在房间列表中。BMO 与我的个人聊天房间始终在列表里。

## TODO 面板

像“帮我修一下这个 bug”这样把工作交给 BMO，BMO 就会把它记为 TODO 条目。在面板的标签页中按“等待”“进行中”等状态分开查看条目；点开条目，可以看到请求原文、进展情况和工作日志。每个条目都带有一个小标记，显示负责这项工作的模型。

## 设置窗口

用户菜单中的“设置”会以大窗口的形式在当前页面之上打开。左侧是项目，右侧是其内容，修改后立即生效。

| 项目 | 用途 |
|---|---|
| “账号” | 登录信息和个人资料（姓名、职称等）、“我向组织共享的信息”、“公开在线状态” |
| “我的 BMO” | 我的 BMO 的名称、称呼、人设和头像。只对组织允许的人显示 |
| “我的智能体” | 组织提供的智能体、我添加或修改的部分，以及“我的指示” |
| “设备” | 连接到我账号的设备及其状态、“断开设备连接” |
| “桌面” | 只有在桌面应用中打开时才显示的应用设置 |
| “密钥保管库” | 不在对话中留下 API 密钥或密码、把它们托管起来的地方 |
| “供给” | 我的智能体靠什么运行、由谁付费 |
| “我的应用·工具”、“我的个人应用” | 开启和关闭应用，以及 BMO 为我做的应用 |
| “主题”、“房间” | 语言、显示模式、自动翻译、主题、房间颜色 |

平台管理员还多出“通知”和“语音简报”。

### 我的 BMO

在“我的 BMO”中可以修改名称、“称呼”和“人设”。每一行下方会显示是“自行设定”还是“公司设定”。关闭“使用人设”后，BMO 保留名称和头像，只是不再接收语气和性格方面的指示。“重置”会清除我自己设定的名称、称呼、头像和人设，回到公司的设置。

## 须知

- 如果从未选择过显示模式，页面会以深色打开。
- 成员只能看到自己的房间和自己能读取的页面。别人的房间或智能体不会出现在任何列表中。
- 能否在房间里发言取决于账号的权限。只被允许读取的人没有输入框。
- “设置”窗口中改动的值无需保存按钮即刻生效。只有像密码这样单独打开的表单才有自己的“保存”按钮。
