## 控制台分为三栏

用安装时设定的名称和密码登录控制台后，页面分为三栏。

- **左侧边栏：** 通往各个页面、房间和智能体的入口。
- **中间：** 当前打开的页面或房间。
- **右侧 TODO 面板：** 交给 BMO 的工作以条目形式堆积在这里。平台管理员的控制台才有。

平台管理员的首页一眼展示房间和智能体此刻在做什么，成员的首页则是自己的房间列表。在手机上，侧边栏以抽屉形式打开，TODO 面板用顶部栏的“打开 TODO”打开。

## 侧边栏

- **“搜索…”** 最上方的搜索在任何地方都能用 Ctrl+K（Mac 上是 ⌘K）打开。可以查找页面及其标签页、房间、智能体，也能按名字查找同一组织的人。
- **页面分组：** 分为三组。
  - “系统服务”：照看部署的管理页面、负责人们使用的页面，以及所有人都能打开的“应用商店”。“组织”“平台设置”“代理中心”“Brain”等都在这里；有账号的人在这一组里至少都能看到“应用商店”。
  - “应用”：“笔记”“日历”“制品”“邮件”这类日常使用的页面。
  - “我的应用”：我的 BMO 为我做的个人应用的页面。应用名称没有用我的语言写成时，会翻译后显示，原来的名称显示在提示框中。
- **“房间”：** 我的房间列表。置顶的房间排在最上面；有新消息时房间会移到上方，并显示未读数。
- **“智能体”：** 平台管理员能看到的主管、角色和仓库列表。
- **下方的用户菜单：** 点自己的名字，有“设置”、桌面应用下载、显示模式（浅色·深色·跟随系统）和“退出登录”。

侧边栏只显示我能打开的页面。一个页面都没有的分组，连标题也不显示。

## 房间

房间是 BMO 和人对话的地方。

- **与 BMO 的个人房间：** 只有我和我的 BMO 两个人的聊天房间。在下方输入框（“对 BMO 说”）中输入，BMO 就会回答。也可以用回形针按钮附上文件。
- **群组房间：** 在侧边栏房间标题旁的“新聊天”中点“创建控制台房间”，填写“房间名称”即可创建。这是不需要聊天服务、只在控制台中使用的房间，由创建者的 BMO 回答。
- **添加成员：** 房间的创建者或他的负责人，可以在“房间信息”的“成员”标签页中用“添加成员”一次加入多人或整个组织。
- **只要是房间成员，就能呼叫自己的 BMO：** 无论是从控制台加入的人，还是与账号相连的聊天服务中的成员，都可以在房间里按名字呼叫自己的 BMO。没有单独的许可列表，加入即获得，离开即失去。
- **“与我的 BMO 单独对话”：** 在群组房间的菜单中。群组房间保持不变，旁边打开一个面板，与我的 BMO 单独交谈。在这里说的话不会发到群组房间。
- **“在对话中查找”和置顶：** 在房间的菜单中查找对话，或置顶、取消置顶房间。
- **“交接会话”和“重置会话”：** 如果我能操作在该房间回答的 BMO，房间的菜单里就有这两项。详见“会话”一章。

把 Telegram 或 Discord 的房间添加到控制台后，它们也会一起出现在房间列表中。BMO 与我的个人聊天房间始终在列表里。

### 房间信息

点房间上方的房间名称，“房间信息”会在宽屏上从侧面打开，在手机上从下方打开。有“成员”“媒体”“文件”“链接”“音乐”“语音”“情况”标签页；平台管理员还多一个“会话信息”，可以修改的房间还多出“聊天服务”和“语气”。

- **“聊天服务”：** 只显示承载这个房间的聊天服务，不能更改。房间的聊天服务在添加或创建房间时确定，之后保持不变。
- **“代答模式”：** 只在聊天服务支持的已添加房间中出现的开关。开启时为“在此房间中，BMO 以你的账号代你回复。”，关闭时为“只记录，不回复。”。

### 系统消息

不属于任何智能体发言的通知，不以气泡显示，而是以居中的一行浅色文字出现。它没有头像也没有名称，因此不会被看成 BMO 说的话。部署或重启导致服务暂停时的提示、有人加入和离开、会话被交接或重置、休息开始等，都以这种方式显示。这些句子来自控制台的语言包，因此会以我的语言显示。

## TODO 面板

像“帮我修一下这个 bug”这样把工作交给 BMO，BMO 就会把它记为 TODO 条目。在面板的标签页中按“等待”“进行中”等状态分开查看条目；点开条目，可以看到请求原文、进展情况和工作日志。每个条目都带有一个小标记，显示负责这项工作的模型。

## 设置窗口

用户菜单中的“设置”会以大窗口的形式在当前页面之上打开。左侧是项目，右侧是其内容，修改后立即生效。

| 项目 | 用途 |
|---|---|
| “账号” | 登录信息和个人资料（姓名、职称等）、“我向组织共享的信息”、“公开在线状态”、“再次查看入门指南”、“安全”（邮箱验证、两步验证、已登录的设备、登录记录） |
| “我的智能体”、“供给”、“我的应用·工具·技能” | 以已选中“我”的状态打开组织页面“智能体”“供给”“应用·工具·技能”标签页的入口 |
| “设备” | 连接到我账号的设备及其状态、“断开设备连接” |
| “桌面” | 只有在桌面应用中打开时才显示的应用设置和“更新渠道” |
| “密钥保管库” | 不在对话中留下 API 密钥或密码、把它们托管起来的地方 |
| “我的个人应用”、“我的技能” | BMO 为我做的应用和 MCP 服务器，以及我自己制作或从应用商店安装的技能 |
| “主题”、“房间” | 语言、显示模式、自动翻译、主题、房间颜色 |

平台管理员还多出“通知”和“语音简报”。

### 我的 BMO

我的 BMO 位于组织页面“智能体”标签页中选择“我”时最上方的“我的 BMO”。只对组织允许的人显示。在这里可以修改名称、“称呼”和“人设”。每一行下方会显示是“自行设定”还是“公司设定”。关闭“使用人设”后，BMO 保留名称和头像，只是不再接收语气和性格方面的指示。“重置”会清除我自己设定的名称、称呼、头像和人设，回到公司的设置。

## 须知

- 如果从未选择过显示模式，页面会以深色打开。
- 成员只能看到自己的房间和自己能读取的页面。别人的房间或智能体不会出现在任何列表中。
- 能否在房间里发言取决于账号的权限。只被允许读取的人没有输入框。
- “设置”窗口中改动的值无需保存按钮即刻生效。只有像密码这样单独打开的表单才有自己的“保存”按钮。
