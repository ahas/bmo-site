## 什么是委托链

BMO 的许多设置是从上往下一环一环传下来的。这条线称为**委托链**。

1. 平台
2. 公司
3. 公司下的各个组织（一直到这个人所属的组织，不论几级）
4. 个人

每一环由负责这一环的人（平台是平台管理员，组织是负责人，个人通常是本人）决定两件事：这项设置的值是什么，以及下面的环能否修改这个值。

一个人的委托链沿着他的所属组织走。即使在其他组织兼职，那个组织的设置也不会传下来。

## 三种选择：沿用上级、允许、锁定

组织页面的每项设置都有“下级组织”一栏，从以下选项中选一个。

| 选择 | 含义 |
|---|---|
| “沿用上级” | 保持上一环的决定，相当于什么都没设定 |
| “允许下级组织” | 表明开放给下面的组织和个人修改 |
| “锁定下级组织” | 固定这项设置，下面所有环都不能修改 |

锁定对下面不论几级的所有人都生效。锁定之前下面的环已设定的值不会被删除，而是原样保存，解除锁定后会重新生效。“允许下级组织”无法解除上面设下的锁定，锁定只能在设下它的位置解除。

平台管理员也可以在被锁定的下级环中填写值，但这个值同样要等锁定解除后才会被读取。

## 值的决定顺序

实际适用于某人的值，是从上往下读委托链来决定的。

- **越近的环胜出。** 如果谁都没有设定，就使用这项设置的默认值。
- **在同一环内，** 按指定这个人的规则、这个人所在群组的规则、指定这个人所属组织的规则、这一环本身的值的顺序，使用最先找到的那个。
- **上面设下的锁定胜过一切。** 锁定之下各环的设定不会被读取。
- **有些设置只能收紧。** 比如供给来源开关或应用的提供，下面的环只能关闭上面开放的，不能重新打开上面关闭的。

## 在页面上是这样显示的

| 页面 | 显示的文字 |
|---|---|
| 组织页面 | “自行设定”，沿用时如“遵循上级组织：开启”，锁定时为“已被上级组织锁定” |
| 我的设置 | “自行设定”“遵循组织”“已被组织锁定”“由组织设定 · 组织名称”，由平台设定时为“由全局设置设定” |

“自行设定”的行上有“恢复”，可以清除我设定的值，回到从上面传下来的值。被锁定的设置，按钮会变灰不可用，下方写明是谁设定的。

## 供给：靠什么运行、由谁付费

供给指的是智能体的一次运行用哪个凭据发出、由谁付费。即使供给来源变了，智能体使用的提供商和模型也不会变。

**智能体供给来源**有三种，运行按这个顺序依次往下。

1. “个人供给”：我的 Claude 登录或我的 API 密钥。由我直接付给提供商。
2. “组织供给”：我所属组织登记的密钥和 Claude 账号。由组织付费。
3. “平台供给”：平台的凭据。用套餐中包含的用量或积分支付。

三种供给来源都是委托链上的设置。“个人供给”和“平台供给”默认开放，组织只能关闭。“组织供给”默认关闭，需要平台管理员为该公司打开“向此公司提供组织供给”才会开放。

组织和平台还设有**供给策略**。策略决定允许“个人供给”“全局供给”“组织积分”“个人积分”中的哪些、按什么顺序使用（“供给顺序”，最后一项总是“停止”），以及一个人每月可用的组织积分上限。新安装平台的默认策略只开启个人供给，由平台付费的供给来源在管理员开启之前一直关闭。

### 我的“供给”设置

在“设置”的“供给”中查看自己这一侧。

- “智能体供给来源”：显示三种供给来源对我是否开启。可以看到是谁设定的，但不能在这里修改。
- “供给登录”：添加我的 Claude 登录并设定顺序。点“添加供给登录”后在浏览器中登录，把得到的代码粘贴到“验证码”，再点“完成登录”。
- “供给密钥”：按名称选择放在密钥保管库中的密钥并关联。密钥的值不会在这个页面上显示。
- “供给顺序”：我要使用的供给来源的顺序和开关，以及个人积分的每月上限。
- “本月用量”：按供给来源显示本月已用量和剩余量。

支付功能处于关闭状态。积分只能由管理员或积分负责人发放来增加，没有充值按钮。

| 设置 | 在哪里设定 |

| “组织指引”、“人设” | 组织页面“智能体”标签页 |
| “加入时配置”、“个人设置许可”、“管理仓库” | 组织页面“智能体”标签页 |
| 应用的提供与开启·关闭 | 组织页面“应用与工具”标签页 |
| 文档“存储位置” | 组织页面“制品存储”标签页 |
| “BMO 设置权限” | 组织页面“BMO”标签页（“允许”“禁止”“遵循上级组织”） |
| 制作个人应用、使用网络·机密、共享范围 | 平台和组织的设置 |

## 改动的设置何时生效

改动的值从下一轮起生效。指引和人设从每个人的下一轮对话起，供给来源从下一次运行开始时起，应用从下一次调用和下一次读取页面起反映。系统不会另行通知改了什么，使用方每次使用时都会重新询问委托链。

## 须知

- 如果谁都没有设定任何东西，大家可以进行与智能体有关的所有个人设置。
- 被上面关闭的供给来源在我的设置中显示为灰色，并附上“已被组织禁止”或“已被管理员禁止”之类的原因。
- “启用供给限制”关闭期间，只记录用量，不会有任何运行因供给而停下。
