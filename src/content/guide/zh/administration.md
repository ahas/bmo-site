## 平台管理员

平台管理员是照看整个 BMO 平台的人。安装时创建的第一个控制台账号就是平台管理员，可以打开侧边栏“系统服务”中的所有页面。成员看不到“平台设置”这一项，即使直接输入地址打开，也会回到首页。

## 平台设置

“平台设置”汇集了针对平台本身的设置。修改后立即生效。

### “提供商”标签页

- **提供商：** 智能体可用的每个提供商都显示剩余用量和一个开关。关掉开关，该提供商会立即停用，并在所有顺序中被跳过。最后一个不能关闭。读取密钥文件的提供商会显示“已有密钥”或“没有密钥”，以及“设置密钥”按钮，密钥的值不会再次显示。
- **“提供商机密”：** 提供商工具按名称选用的机密。
- **“Claude 账号”：** Claude Code 依次使用的 Claude 账号列表。在“添加账号”中选择“在此登录”，无需终端即可登录：用“打开登录页面”在浏览器中授权，把得到的代码粘贴到“验证码”，再点“完成登录”。拖动可以调整顺序；用菜单中的“现在用这个账号”指定一个账号，或用“按顺序”恢复轮流使用。任何页面都不会显示令牌或凭据内容。
- **部署的“批量部署间隔”：** 决定每隔几分钟把等待部署的提交一次性上线。

### “机密类型”标签页

决定每个人的密钥保管库表单要询问哪些类型（例如一对密钥和密码）。在“添加类型”中填写键、名称、说明和字段（单行、多行、文件、隐藏值、必填）。这里只有类型，没有机密的值。

### “套餐”和“积分”标签页

- 在“套餐”中创建个人和组织套餐，包括名称、价格、周期以及每个周期发放的积分。组织在组织页面的“套餐”标签页中，从已公开的套餐里选一个使用。
- 在“积分”中设定“平台默认策略”“换算率”“预留积分”“启用供给限制”，并给人员或组织“发放积分”。所有变动都记录在“账本”和“审计记录”中。

支付功能处于关闭状态。积分只能通过发放增加；“启用供给限制”关闭期间，只记录用量，不会让任何运行停下。

## 应用管理与紧急收回

整个平台的应用，在组织页面的树中选择“整个平台”后，在“应用与工具”标签页中管理。

- **“提供”：** 公司没有另行设定时，是否提供这个应用。
- **“开启”·“关闭”：** 谁都没有另行设定时，应用是否开启。应用制作方设定的值旁会标上“（默认）”。
- **“锁定下级组织”：** 对所有公司、组织和个人固定这一设定。
- **“紧急收回”：** 一次性在所有地方关闭应用。系统会询问“要在所有地方关闭（应用名称）应用吗？”，点“收回”后状态变为“已紧急收回”。解除收回之前谁都无法开启，但公司、组织和个人设定的值会保留，点“解除收回”后重新生效。

同一页面的“平台应用申请”汇集了各公司发来的请求，希望把共享的个人应用做成平台应用。管理员阅读源代码后决定是否发布。

## 人员与权限

- **创建账号：** 在组织页面的“邀请”标签页中，用“创建邀请链接”生成链接并交给对方。只有管理员可以以“负责人”角色发出邀请。
- **“用户”标签页：** 查看平台上的所有人。打开一个人，会看到“账号”“组织”“权限”“BMO”“供给”“活动”标签页；在“管理”菜单中可以进行“调动组织”“添加兼职”“连接设备”“编辑个人资料”“BMO 设置权限”“办理离职”。
- **“权限”：** 按区域用“读取”和“写入”开关，决定这个人可以读写控制台的哪些区域。平台管理员可以写入所有区域，因此无需修改。
- **“活动”：** 查看这个人的房间、智能体、会话和最近的运行。管理员打开别人的个人房间时是只读的，已读痕迹不会传给房间里的人。
- **“办理离职”：** 无法撤销。这个人将无法再登录，他的 BMO 也不会再被唤醒。个人工作、个人对话和 BMO 的记忆只有平台管理员可以读取。

唯一的例外是密钥保管库。每个人的机密值都放在只属于本人的空间里，平台管理员也无法读取。

## 其他管理页面

| 页面 | 用途 |
|---|---|
| “代理中心” | 在“角色”“智能体”“仓库”“注册模型”“模型文件”标签页中管理智能体的角色、提供商与模型、工作仓库，以及自有模型引擎 |
| “Brain” | 查看和修改所有大脑的记忆，审查全局记忆候选 |
| “监控” | 通过“设备”“节点”“服务”“日志”标签页查看 GPU 节点的显卡和服务状态（`operator` 安装） |
| “缓存警报” | 实时观察提示词缓存命中和新令牌（`operator` 安装） |
| “调研” | 调研运行及其设置（`team` 及以上） |
| “DB”、“文档查看器” | 直接查看数据和文档 |

安装类型中没有的页面，会从侧边栏和搜索中完全去掉。

## 上线新版本

安装完成后，各仓库的新提交通过 BMO 的部署流程上线。等待部署的提交会按“批量部署间隔”一次性上线。新增一个仓库由 BMO 负责，并且只有在主人批准了该仓库时才会进行。

## 须知

- 第一个账号的名称和密码在安装时设定。忘记密码时，在服务器上用 [bmo-web](https://github.com/ahas/bmo-web) 的账号命令重新设定。
- 平台管理员可以在组织页面中为每家公司打开或关闭“向此公司提供组织供给”。
- 浏览器通知和语音简报在管理员“设置”中的“通知”“语音简报”里设定。
