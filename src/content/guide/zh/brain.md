## 大脑是 BMO 的长期记忆

大脑是一个智能体的长期记忆。除了对话本身，BMO 对世界的一切了解都从大脑中读取。发生过的事、事实、人的名字、房间的规则、人设，都以一条一条的记忆存放在里面。

- **每个智能体都有自己的大脑。** 同一账号下的两个智能体也看不到彼此的记忆，其他账号的大脑就更看不到了。
- **不删除，而是累积版本。** 修改记忆会产生新版本，不再正确的记忆只是被关闭并隐藏，不会被删除。谁在什么时候改了什么，都可以从版本中读到。
- **不会因为时间久而遗忘。** 记忆不会因为陈旧或没被使用而变淡。只有在结束条件达成、被修改，或被人结束时，记忆才会结束。

## 记住哪些内容

| 类型 | 含义 |
|---|---|
| “情节” | 按原话记下发生过的事，是以后整理成事实的素材 |
| “事实” | 已确认如此的事 |
| “传闻” | 从别人那里听来或推测的事，不会覆盖事实 |
| “情境规则” | 遇到某种情境时该做什么 |
| “房间规则” | 某个房间里允许的规则 |
| “名称” | 称呼某人或某物的名字 |
| “人设” | 构成 BMO 语气和性格的片段 |
| “世界观”、“知识” | 作为参考阅读的设定和知识 |

还有“约定”“后续待办”“技巧”“检查”这类由 BMO 自己决定使用的类型。

### BMO 写入记忆的方式

BMO 一边阅读对话，一边当场决定要记住什么并写下来。

- **本人说的话直接成为事实。** 某人关于自己说的话，以及主人下达的指示，会直接记为事实，并关闭与之矛盾的旧事实。
- **别人的事和推测记为“传闻”。** 本人确认或有其他来源证实后，才会成为事实。
- **写入前先查找相似的记忆。** 内容相同就不新写，只做确认；是补充就写成新版本；有矛盾就关闭旧的再写新的。
- **记忆以英语保存。** 无论在房间里用什么语言说，记忆本身都用英语写下。
- **在一个房间里说的话，作为那个房间的记忆保留。** 不会随意在别的房间提起。

### 对话时回想的方式

BMO 不会每一轮都读取所有记忆，而是挑出与当前对话相关的记忆，以简短的一组接收。如果在记忆上写明“什么时候需要”和“什么时候结束”，那个情境出现时它就会被想起，结束的情境出现时就会退下。

## 三个层

BMO 读取记忆时，会由近到远查看三层。

1. **我的 BMO 的大脑：** 始终读取。
2. **组织记忆：** 我所属各组织的记忆，越近的组织越优先。
3. **全局记忆：** 对任何组织的任何智能体都有用的技巧和知识。

多个层拥有同一主题时，较近的层胜出。例如团队的工作时间优先于公司的工作时间。不过，上级组织“固定”的主题，下级组织不能覆盖。是否读取组织记忆和全局记忆，由平台和组织通过委托链的设置决定。

组织记忆只收录适用于整个组织的内容，以及关于个人的、组织可以知道的内容，例如角色、负责的工作、希望的联系方式。个人情况、健康、在我的对话中说过的话、对人的评价，只留在各自 BMO 的大脑里。组织记忆只在一家公司内部使用。

## 查看和修改记忆的地方

### “我向组织共享的信息”

位于“设置”的“账号”中。可以查看所属组织的记忆中与我有关的内容，用“添加信息”写下组织可以知道的我的信息，或用“删除信息”撤下。

### “组织记忆”标签页

负责人和获得写入权限的人，在组织页面的“组织记忆”标签页中添加和修改组织的记忆。成员留下的内容不会立即生效，而是汇集为“提议”，负责人“接受”后才成为事实。由其他服务管理的记忆不能在这里修改，只显示它来自哪里。

### “Brain”页面

平台管理员在侧边栏“系统服务”的“Brain”中查看所有大脑。

- 先在最上方选择一个大脑，再在左侧用“层”“对象”“类型”缩小范围。选择一个人时，会一并显示“人物概要”。
- 打开一条记忆，右侧会显示状态、层、对象、版本历史、使用程度和写入者。
- 用“正确”确认，用“已结束”“不正确”关闭，用“撤回说法”把它变成从一开始就不成立的话。已关闭的记忆可以用“恢复”重新启用。
- “修改”会生成新版本。如果在此期间 BMO 先改过，会显示新版本，并保留你正在写的内容。
- 在“添加记忆·层”中选择“教授”，会显示相似的记忆，由你判断是重复、补充、矛盾还是全新的内容，然后教给它。
- 用“翻译”可以用你的语言阅读记忆。用韩语写的内容，会在保存前翻译成英语给你看并请你确认。

全局记忆只由平台管理员写入。从多个 BMO 学到的技巧和知识中挑出候选，管理员在“审查”中逐条“升为全局”、留在原来的大脑中，或丢弃。

## 须知

- 大脑自己什么都不做。写入和读取记忆的是 BMO 和页面，大脑只负责以版本形式保存。
- 人设从大脑的“人设”层读取，放入 BMO 的系统提示词。修改片段后，叠在其上的提示词缓存会重新开始一次。
- 大脑的仓库和结构文档在 [bmo-brain](https://github.com/ahas/bmo-brain)。
