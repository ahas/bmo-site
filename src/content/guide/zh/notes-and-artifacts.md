## 笔记和制品有什么不同

| | 笔记 | 制品 |
|---|---|---|
| 谁来写 | 我自己写、自己改 | 主要由 BMO 或调研生成并保存 |
| 是什么 | 边改边写的文档 | 整理好的记录、调研结果、学习资料、保存下来的网页 |
| 分享 | 链接，给公司里的人查看或编辑权限 | 链接，给公司里的人、整个组织查看权限 |

## 笔记

从侧边栏“应用”中的“笔记”打开。

### 列表

左侧列表中有“书签”“我的笔记”“与我共享的笔记”，最下方是“回收站”。在“我的笔记”中可以用“新建文件夹”建立最多八级的文件夹。文件夹是我自己的整理方式，不会共享给别人。删除文件夹时，里面的笔记不会被删除，而是上移一级。

### 编写

点“新建笔记”，写下标题和正文。正文中可以插入标题、列表、待办列表、引用、代码块、表格和图片，每篇笔记还可以加一个表情符号图标。

- 边写边自动保存，上方会显示“正在保存…”“已保存”。
- 一篇笔记同一时间只能由一个人修改。如果别处先保存了，会提示“此笔记已在别处保存。”并让你重新加载。
- 用 Ctrl+Z 撤销，用 Ctrl+Shift+Z 或 Ctrl+Y 重做。
- 输入 `[[` 或 `@` 可以选择其他笔记并加上链接。笔记下方会列出链接到这篇笔记的其他笔记。

### 书签与评论

- 可以给笔记、文件夹以及笔记中的某一行（“行书签”）加书签。行书签会跟着那一行走，即使它被移动或内容有变化。
- 选中文字添加评论，那一行下方会展开一段讨论。讨论可以标记为已解决收起来，之后再打开。

### 查找与共享

用 Ctrl+K 打开搜索窗口。可以搜索标题和正文，并选择排序（最匹配、最近修改、创建日期）和筛选（仅标题、我的笔记、与我共享的笔记、回收站、修改日期）。

“共享”分为两种。

- **链接：** 在设定的期限内或不限期打开的只读链接。不登录也能查看。
- **公司里的人：** 给同一公司的人查看或编辑权限。有编辑权限的人也可以添加评论。

回收站、彻底删除以及修改共享本身，只有笔记的所有者才能操作。

### 在笔记中与 BMO 一起写

- **“Agent”：** 选中文字后点“Agent”，会出现润色、修正拼写和语法、扩写·缩写、改变语气、韩语·英语·日语翻译、续写、摘要、大纲等菜单。也可以用自己的话直接提出请求。结果先显示在下方，由我选择替换、插入到下方、重新请求或丢弃。
- **“讨论”：** 在笔记旁打开一个面板，就整篇笔记与我的 BMO 的笔记助手交谈。它只把改动的部分改进笔记里；改不进去时，会用一句话说明原因。“全部应用”会用回答覆盖整篇笔记的文字。

无论哪种方式，都可以用一次撤销把 BMO 的修改还原。

### 笔记没有的功能

笔记没有版本记录、多人同时编辑和封面图片。图片中的文字不会被搜索到。

## 制品

侧边栏“应用”中的“制品”汇集了 BMO 为我保存的文档。在房间里说“整理一下留成文档”，BMO 或调研就会把结果存到这里，并把链接发给你。

### 文档的类型

| 类型 | 内容 |
|---|---|
| “调研” | 调研找到的内容：核心答案、三行摘要、作为依据的页面 |
| “记录” | 整理好的资料 |
| “学习资料” | 像书一样按部、章、节编排的学习资料 |
| “原文” | 整篇保存下来的网页 |
| “页面” | 原样保存的 HTML 页面 |

### 首页与列表

首页有“最新文档”、按类型分组的内容，宽屏时侧栏还有“分类”“最近查看”“最多查看”（“最近 7 天”）。输入搜索词后会切换为列表，可以按类型筛选。也可以用文档编号（如 `#31`）查找。

### 阅读文档

打开文档，会显示正文以及“目录”“参考页面”和附件。带有朗读语音的文档有“边听边看”。右上方有“翻译”（文档语言与我的语言不同时）、“指令”、“下载”、“共享”和信息查看。

### 谁能阅读

- 文档起初只有所有者能读。即使是同一组织的负责人，在被共享之前也读不到。平台管理员可以读取所有文档，但不会修改别人的文档。
- 用“共享”可以分享给三种对象：链接（设定期限或不限期）、同一公司的人，以及用“共享给组织”分享给一个组织及其下所有人。分享给公司的人和组织都是只读的。
- 在列表中，开放了链接的文档会标上“公开”或“公开 · 至某日”，否则标上“不公开”。

文档文件保存在哪里，由组织页面的“制品存储”标签页决定。

## 须知

- 文档的共享链接如果不设期限，即使服务重启或部署了新版本，也会一直可以打开。
- 过期的链接只会说明它原本打开的是什么，不显示正文。
- 所有者离开公司后，已共享的文档被共享的人仍可继续阅读，未共享的文档则被锁定。
