## BMO 这样安装

BMO 是运行在你自己电脑上的 AI 智能体平台。你在网页控制台中与 BMO 对话，BMO 会积累记忆（大脑），并和你一起处理笔记、文档、日历、文件等工作。

安装 BMO 不需要人逐条照着输入命令。在要运行 BMO 的电脑上打开 Claude Code 或 Codex 这类编程智能体，把下面这句话原样交给它即可。

```
阅读 https://bmo.ahas.io/install.md，在这台机器上安装 BMO。
```

智能体会从头到尾读完安装手册，然后亲自执行所有命令。它只问只有人才知道的事：想要哪种安装、聊天机器人的令牌、控制台使用的名称和密码、域名、需要在浏览器中完成的登录，以及电脑要求管理员权限时的批准。一个步骤需要问的问题会集中起来一次问完。

## 准备好电脑

| 项目 | 要求 |
|---|---|
| 操作系统 | Linux。软件包名称以 Debian·Ubuntu 系为准 |
| 处理器 | 64 位 x86 或 ARM |
| 账号 | 非 root 的普通用户 |
| 内存 | 16GB 以上（内存不足时构建可能卡住，因此会先询问） |
| 磁盘 | 60GB 以上可用空间 |
| 网络 | 必须能访问 GitHub |

没有 systemd 的电脑也可以安装。这时由 BMO 测试台自带的监管程序代为运行各项服务。

## 三种安装类型

智能体一开始会问一次你想要哪种安装。安装类型定义在公开仓库的 `presets.toml` 中。

| 安装类型 | 包含什么 |
|---|---|
| `personal`（个人） | 一个人和他的 BMO。控制台、记忆、编程智能体、一个聊天服务、文档、笔记、日历、文件、邮件、远程桌面。不含组织功能和需要 GPU 的功能 |
| `team`（团队） | 在个人安装的基础上，加上公司、组织、成员、房间权限、代码审查和调研 |
| `operator`（运营者） | 公开的全部内容。用户之声、BMO 的面孔、GPU 节点上的语音与视觉、GPU 显卡共享、节点监控、视频库、远程机器中心。需要 GPU 机器、域名和反向代理 |

`personal` 和 `team` 除了网页控制台，还要选一个与 BMO 对话的聊天服务：Telegram 或 Discord 二选一；`operator` 两者都安装。

## 安装时询问的值

| 值 | 含义 |
|---|---|
| 控制台名称和密码 | 登录控制台时使用的名称和密码，由你自己设定 |
| 控制台地址 | 打开控制台的地址。不使用域名时，在这台电脑内用 3210 端口的 `/bmo/` 地址打开 |
| BMO 对你的称呼 | 对话中 BMO 怎样称呼你 |
| 聊天服务中你的 ID 和语言 | 你在聊天服务中的 ID，以及 BMO 回复你时使用的语言 |
| 机器人令牌 | Telegram 或 Discord 机器人的令牌 |
| 远程桌面密码 | 控制台打开的远程桌面的密码 |

机密值不会留在命令行、日志或智能体的回答中。智能体把值写进临时文件交给安装程序，随后立即删除。

## 安装做了什么

1. 先用不改动任何东西的试运行展示整个计划。
2. 下载安装类型中包含的所有仓库。
3. 检查所需的程序、端口和输入值，创建数据库和配置文件。
4. 逐个首次部署各仓库，创建第一个控制台账号、第一个聊天智能体和你自己的房间。
5. 检查所有服务的状态，并向你的房间发送一条测试消息。

中途即使有什么失败，也不必从头再来。再次运行同一个安装，会从停下的地方继续。

## 安装完成后

智能体会告诉你控制台地址、登录名（不会说出密码）、安装的类型和聊天服务。打开控制台登录后，也给聊天机器人发一条消息，确认 BMO 会回复。

安装之后再添加一个仓库（例如 `bmo-research`）是 BMO 自己的工作。BMO 只有在你批准了那一个仓库时才会添加。新版本通过 BMO 的部署流程上线。

## All-in-One 桌面应用

如果想不经编程智能体、直接在自己的电脑上放一个 BMO，可以用 **BMO All-in-One** 应用。它在这台电脑上安装并运行个人安装（`personal`），并在应用窗口中打开控制台。不需要单独的服务器。

- **要求：** 内存 16GB、磁盘 60GB 的 Linux，或启用 WSL 2 的 Windows。在 Windows 上，它运行在名为 `BMO` 的 WSL 2 发行版中。
- **首次运行：** 先展示会把什么装到哪里并征得同意，然后按检查电脑、准备、安装所需程序、输入值、安装的顺序一屏一屏进行。管理员权限只通过操作系统自己的确认窗口请求。
- **运行中：** 托盘图标可以打开控制台并显示状态。退出应用时 BMO 服务也一起停止，重新打开应用时再次启动。
- **更新：** 应用本身通过应用的更新功能更新；BMO 的各个仓库和服务器一样，通过 BMO 自己的部署获取新版本。

如果已经有 BMO 服务器，就用 **BMO 远程控制器**应用。它在窗口中打开服务器的控制台，并把这台电脑接入为 BMO 可以工作的设备。两个应用都由 [jake](https://github.com/ahas/jake) 仓库构建。

## 须知

- 安装手册原文是 [install.md](https://bmo.ahas.io/install.md)，安装类型在 [bmo 仓库](https://github.com/ahas/bmo)的 `presets.toml` 中。
- 所有设置和机密都集中在一个数据文件夹（`~/.local/share/bmo/data`）下。
- 已被其他程序占用的端口会避开，改用下一个空闲端口。
- All-in-One 应用的 Windows 路径已经做好，但据文档所说，还没有到在真实 Windows 上运行过的阶段。
