## ノートとアーティファクトはどう違うのか

| | ノート | アーティファクト |
|---|---|---|
| だれが書くか | 自分で書いて直します | 主に BMO やリサーチが作って保管します |
| 何なのか | 直しながら書くドキュメント | 整理された記録、リサーチの結果、学習資料、取り込んだ Web ページ |
| 共有 | リンク、会社の人に閲覧または編集 | リンク、会社の人、組織全体に閲覧 |

## ノート

サイドバーの「アプリケーション」にある「ノート」で開きます。

### 一覧

左の一覧には、「ブックマーク」、「マイノート」、「共有されたノート」、そしていちばん下に「ゴミ箱」があります。「マイノート」では、「新しいフォルダー」でフォルダーを 8 階層まで作れます。フォルダーは自分だけの整理方法なので、ほかの人には共有されません。フォルダーを消しても中のノートは消えず、ひとつ上の階層に移ります。

### 書く

「新しいノート」を押して、タイトルと本文を書きます。本文には見出し、リスト、ToDo リスト、引用、コードブロック、表、画像を入れられ、ノートごとに絵文字のアイコンをひとつ付けられます。

- 書いたそばから自動で保存され、上に「保存中…」、「保存済み」と表示されます。
- ひとつのノートを直せるのは、一度にひとりだけです。別の場所で先に保存されていた場合は「このノートは別の場所で保存されました。」と知らせ、読み込み直してもらいます。
- Ctrl+Z で元に戻し、Ctrl+Shift+Z または Ctrl+Y でやり直します。
- `[[` か `@` を入力すると、ほかのノートを選んでリンクできます。ノートの下には、このノートにリンクしているノートが表示されます。

### ブックマークとコメント

- ノートとフォルダー、そしてノートの 1 行（「行をブックマーク」）をブックマークできます。行のブックマークは、その行が移動したり内容が変わったりしてもついていきます。
- 文字を選んでコメントを付けると、その行の下にスレッドが開きます。スレッドは解決として畳んでおき、あとで開き直せます。

### 検索と共有

Ctrl+K で検索ウィンドウを開きます。タイトルと本文を検索し、並べ替え（関連度順、最近の更新、作成日）とフィルター（タイトルのみ、マイノート、共有されたノート、ゴミ箱、更新日）を選べます。

「共有」では、2 つに分かれます。

- **リンク:** 決めた期間のあいだ、または期限なしで開ける閲覧専用のリンクです。ログインせずに見られます。
- **会社の人:** 同じ会社の人に閲覧または編集の権限を与えます。編集の権限があれば、コメントも付けられます。

ゴミ箱、完全な削除、共有そのものの変更は、ノートのオーナーだけが行えます。

### ノートで BMO と一緒に書く

- **「Agent」:** 文章を選んで「Agent」を押すと、推敲、スペルと文法の修正、長く・短く、トーンの変更、韓国語・英語・日本語への翻訳、続きを書く、要約、アウトラインといったメニューが表示されます。自分の言葉で直接頼むこともできます。結果はまず下に表示され、置き換える、下に挿入する、もう一度頼む、捨てる、から選びます。
- **「相談」:** ノートの横にパネルを開き、ノート全体について自分の BMO のノートアシスタントと話します。変わった部分だけをノートに書き込み、書き込めないときは 1 行で理由を伝えます。「すべて適用」は、ノートの文章全体を回答で上書きします。

どちらの場合も、一度元に戻すだけで、 BMO が直した内容を元に戻せます。

### ノートにないもの

ノートには、バージョン履歴、複数人での同時編集、カバー画像はありません。画像の中の文字は検索されません。

## アーティファクト

サイドバーの「アプリケーション」にある「アーティファクト」は、BMO が自分のために保管したドキュメントをまとめて見る場所です。ルームで「まとめてドキュメントに残して」と頼むと、BMO やリサーチが結果をここに残し、リンクを渡してくれます。

### ドキュメントの種類

| 種類 | 内容 |
|---|---|
| 「リサーチ」 | リサーチが見つけたもの。要点の答え、3 行の要約、根拠になったページ |
| 「記録」 | 整理しておいた資料 |
| 「学習資料」 | 本のように部、章、節にまとめた学習用の資料 |
| 「原文」 | 丸ごと取り込んだ Web ページ |
| 「ページ」 | そのまま保管した HTML ページ |

### 最初の画面と一覧

最初の画面には、「最新の文書」、種類ごとのまとまり、そして広い画面では横の列に「種類」、「最近読んだ文書」、「よく読まれている文書」（「過去7日間」）があります。検索語を入力すると一覧に切り替わり、種類で絞り込めます。ドキュメント番号（`#31` など）でも探せます。

### ドキュメントを読む

ドキュメントを開くと、本文と「目次」、「参照ページ」、添付ファイルが表示されます。読み上げ音声が付いたドキュメントには「聞きながら読む」があります。右上には、「翻訳」（自分の言語とは別の言語で書かれたドキュメントのとき）、「指示文」、「ダウンロード」、「共有」、情報の表示があります。

### だれが読めるのか

- ドキュメントは、最初はオーナーだけが読めます。同じ組織の組織長も、共有されるまでは読めません。プラットフォーム管理者はすべてのドキュメントを読めますが、ほかの人のドキュメントを変更することはありません。
- 「共有」では、3 つの方法で共有できます。リンク（期間を決めて、または期限なしで）、同じ会社の人、そして「組織に共有」でひとつの組織とその下のすべての人。会社の人と組織への共有は閲覧専用です。
- 一覧では、リンクが開いているドキュメントに「公開」か「公開・日付まで」、そうでなければ「非公開」が付きます。

ドキュメントのファイルをどこに保管するかは、組織画面の「アーティファクトの保存」タブで決まります。

## 知っておくこと

- ドキュメントの共有リンクは、期間を決めなければ、サービスが再起動しても新しいバージョンがデプロイされても開き続けます。
- 期限の切れたリンクは、何を開くリンクだったかだけを残し、本文は表示しません。
- オーナーが会社を離れても、共有されたドキュメントは共有された人が引き続き読め、共有していないドキュメントはロックされます。
