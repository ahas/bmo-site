## コンソールは 3 つの列に分かれています

インストールのときに決めた名前とパスワードでコンソールにログインすると、画面は 3 つの列に分かれます。

- **左のサイドバー:** 画面、ルーム、エージェントへの入り口です。
- **中央:** いま開いている画面やルームです。
- **右の TODO パネル:** BMO に任せた仕事が項目として積み上がる場所です。プラットフォーム管理者のコンソールにあります。

プラットフォーム管理者の最初の画面では、ルームとエージェントがいま何をしているかがひと目でわかり、メンバーの最初の画面は自分のルーム一覧です。スマートフォンではサイドバーが引き出しとして開き、TODO パネルは上のバーの「TODO を開く」で開きます。

## サイドバー

- **「検索…」** いちばん上の検索は、Ctrl+K（Mac は ⌘K）でどこからでも開けます。画面とそのタブ、ルーム、エージェントを探せるほか、同じ組織の人も名前で探せます。
- **画面のグループ:** 3 つのグループに分かれています。
  - 「システムサービス」: デプロイを管理する画面と、組織長が使う画面です。「組織」、「プラットフォーム設定」、「エージェンシー」、「ブレイン」などがここにあります。
  - 「アプリケーション」: 「ノート」、「カレンダー」、「アーティファクト」、「アプリカタログ」のように、日々使う画面です。
  - 「マイアプリ」: 自分の BMO が作ってくれた個人アプリの画面です。
- **「ルーム」:** 自分のルーム一覧です。固定したルームがいちばん上に並び、新しいメッセージが届くとそのルームが上に移り、未読数が付きます。
- **「エージェント」:** プラットフォーム管理者に表示される、スーパーバイザー、ロール、リポジトリの一覧です。
- **下のユーザーメニュー:** 自分の名前を押すと、「設定」、デスクトップアプリのダウンロード、画面モード（ライト・ダーク・システム）、「ログアウト」があります。

サイドバーには、自分が開ける画面だけが表示されます。画面がひとつもないグループは、見出しごと表示されません。

## ルーム

ルームは、BMO と人が会話する場所です。

- **BMO との個人ルーム:** 自分と自分の BMO だけの会話ルームです。下の入力欄（「BMO に話しかける」）に書くと BMO が答えます。クリップのボタンでファイルも添付できます。
- **グループルーム:** サイドバーのルームの見出しの横にある「新しいチャット」で「コンソールのルームを作成」を押し、「ルーム名」を入力して作ります。チャットサービスを使わずコンソールの中だけで使うルームで、作った人の BMO が答えます。
- **メンバーの追加:** ルームを作った人やその人の組織長は、「ルーム情報」の「メンバー」タブにある「メンバーを追加」で、人や組織をまとめて招き入れられます。「呼び出しを許可」をオンにしておくと、入った人が自分の BMO を名前でルームに呼べます。
- **「呼び出し権限」:** 「ルーム情報」のタブのひとつで、このルームでだれが自分の BMO を呼べるかを確認し、変更します。
- **「自分の BMO と個別に話す」:** グループルームのメニューにあります。グループルームはそのままに、横にパネルが開いて、自分の BMO と 1 対 1 で話せます。ここで話したことはグループルームには流れません。
- **「会話内を検索」と固定:** ルームのメニューから会話を検索したり、ルームを固定・固定解除したりします。

Telegram や Discord のルームもコンソールに追加しておくと、ルーム一覧に一緒に表示されます。BMO と自分の個人ルームは、いつも一覧にあります。

## TODO パネル

BMO に「このバグを直して」のように仕事を任せると、BMO はその仕事を TODO 項目として登録します。パネルのタブで「待機」、「進行中」のような状態ごとに項目を分けて見られ、項目を押すと、依頼の原文、進み具合、作業ログを確認できます。項目ごとに、その仕事を担当するモデルが小さな印で表示されます。

## 設定ウィンドウ

ユーザーメニューの「設定」は、いまの画面の上に大きなウィンドウで開きます。左に項目、右にその内容があり、変更はすぐに反映されます。

| 項目 | できること |
|---|---|
| 「アカウント」 | ログイン情報とプロフィール（名前、肩書きなど）、「組織に共有した自分の情報」、「オンライン状態を公開」 |
| 「マイBMO」 | 自分の BMO の名前、呼び名、ペルソナ、プロフィール写真。組織が許可した人にだけ表示されます |
| 「マイエージェント」 | 組織から与えられたエージェントと、自分で追加・変更したもの、「自分の指示」 |
| 「デバイス」 | 自分のアカウントにつながっているデバイスとその状態、「デバイスの接続を解除」 |
| 「デスクトップ」 | デスクトップアプリの中で開いたときだけ表示されるアプリの設定 |
| 「シークレット保管庫」 | API キーやパスワードを、会話に残さずに預ける場所 |
| 「供給」 | 自分のエージェントが何で動き、だれが費用を払うか |
| 「マイアプリ・ツール」、「マイ個人アプリ」 | アプリのオン・オフ、BMO が作った自分のアプリ |
| 「テーマ」、「ルーム」 | 言語、画面モード、自動翻訳、テーマ、ルームの色 |

プラットフォーム管理者には、「通知」と「ボイスブリーフィング」も表示されます。

### マイBMO

「マイBMO」では、名前、「呼び名」、「ペルソナ」を変更できます。各行の下には、「自分で設定」か「会社で設定」かが表示されます。「ペルソナを使う」をオフにすると、BMO は名前と写真はそのままに、話し方と性格の指示だけを受け取らなくなります。「リセット」は、自分で決めた名前、呼び名、写真、ペルソナを消して、会社の設定に戻します。

## 知っておくこと

- 画面モードを選んだことがなければ、ダークモードで開きます。
- メンバーには、自分のルームと自分が読める画面だけが表示されます。ほかの人のルームやエージェントは、どの一覧にも出てきません。
- ルームで書き込めるかどうかは、アカウントの権限によります。閲覧だけが許可された人には入力欄がありません。
- 「設定」ウィンドウで変更した値は、保存ボタンなしですぐに反映されます。パスワードのように別に開くフォームだけに、専用の「保存」ボタンがあります。
